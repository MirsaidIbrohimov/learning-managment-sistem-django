Ma’lumotlarni öçiriş yöriqnomasi

Oxirgi yangilaniş: {{ updated }}

IT Creative Academy ({{ site_url }}) foydalanuvçisi sifatida siz Google, Facebook yoki GitHub orqali olingan ma’lumotlaringizni, şuningdek butun hisobingizni istalgan vaqtda öçirişingiz mumkin.

1. Faqat Google, Facebook yoki GitHub ulanişini öçiriş

  1. Saytga kiring va Profil sahifasini oçing.
  2. «Ulangan hisoblar» bölimida Google, Facebook yoki GitHub qatoridagi «Uziş» tugmasini bosing.
  3. Şu zahoti öşa xizmatdan olingan barça ma’lumotlar (hisob ID, ism, email, rasm havolasi) serverimizdan butunlay öçiriladi.

2. Facebook tomonidan ruxsatni bekor qiliş

  1. Facebook’da Sozlamalar va maxfiylik → Sozlamalar → Ilovalar va veb-saytlar bölimini oçing.
  2. Röyxatdan IT Creative Academy ni toping va «Öçiriş» (Remove) tugmasini bosing.
  3. Şundan keyin ilovamiz Facebook hisobingizdan heç qanday ma’lumot ololmaydi. Saytdagi ulanişni ham 1-banddagi kabi uzib qöyişingizni tavsiya qilamiz.

3. Google tomonidan ruxsatni bekor qiliş

  1. myaccount.google.com/connections sahifasini oçing.
  2. IT Creative Academy ni tanlab, «Ulanişni öçiriş» tugmasini bosing.

4. Butun hisobni va barça ma’lumotlarni öçiriş

  1. Saytdagi «Yordam» bölimi orqali «Hisobimni öçiring» mazmunida murojaat yuboring{% if contact_email %} yoki {{ contact_email }} manziliga xat yozing{% endif %}. Xatda login yoki telefon raqamingizni körsating.
  2. Biz şaxsingizni tasdiqlaş uçun siz bilan boğlanamiz.
  3. Hisobingiz va unga tegişli şaxsiy ma’lumotlar 30 kun içida öçiriladi. Qonun böyiça saqlanişi şart bölgan tölov yozuvlari bundan mustasno.
